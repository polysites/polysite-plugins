# Contributing

Contributions to this repository follow the core repository's guide, including how to set up a development stack, the conventions, and the contribution terms:
[CONTRIBUTING.md](https://github.com/polysites/polysite/blob/main/CONTRIBUTING.md). This repository is mounted into the core's stack
(`plugins/`); open the pull request here, and the checklist in the template applies.

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
